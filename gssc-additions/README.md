# GSSC document additions

Design tokens and a legal-doctrine addendum for GSSC documents. These files are reference material: they are not used by the website and nothing here changes how gsscph.com renders.

- `design-tokens/gssc-hero-notice-derivative.css`: sealed cover, title page and notice components for GSSC documents.
- `design-tokens/gssc-agreement-derivative.css`: master-agreement components (key terms, signatures, acknowledgment).
- `kernel-proposals/09_legal_doctrine.notarial_addendum.json`: the notarial and execution page order and acknowledgment elements, with their statutory references.
