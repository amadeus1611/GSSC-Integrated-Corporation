# Decision: orchestrator effort and delegation (2026-09-25)

Approved by Duke.

## Recommendation
- **The orchestrator runs at high** in Claude Code and in the EXPIRA Console.
  In Claude Code, drop to medium only for an exact change list, a single-file
  tweak or a copy edit. Never low.
- **Desks and sub-agents run at high by default.** In Claude Code the only
  medium agents are firewall-medium and research-medium (parallel batches of
  lookups); single mechanical steps run inline. Nothing runs at low or quick.
- **No decision agent.** The orchestrator plans, assigns, synthesises across
  roles and makes the recommendation itself.

## Reasoning
- Context re-reading, not thinking, dominates cost. One bad plan cost a
  whole iteration: v38 was reverted to v37.
- The only log data (v38: 10 launches, all at medium, no step redos) missed
  that redo, because it happened at the request level. The log now records a
  request row, so the next review has real evidence.
- v38 split one surface across five builders and broke at the seams, so one
  surface is now built in one place.
- A decision agent starts cold and re-reads everything the orchestrator
  already holds, and synthesis *is* the decision. reviewer-high provides the
  independent challenge instead.

## What changed
- `.claude/agents/`: seven agents: research-high, research-medium,
  finance-high, legal-high, builder-high, reviewer-high, firewall-medium.
  Added builder-high and reviewer-high; removed builder-medium and
  reviewer-medium (inline is cheaper than a cold agent); research-high is
  the default researcher; removed decision-medium and decision-high; the
  firewall moved from low to medium; the "lowest tier" wording is gone.
- `orchestrator/POLICY.md`, the orchestrate skill and `CLAUDE.md` all state
  the same rules: effort, inline versus delegate, hand-off format,
  escalation.
- Console v40: no decision desk; the planner, arbiter and final synthesis run
  at the complex tier; desks default to high; low-level calls moved from
  quick to default. The About panel, colophon and lens were updated to match.
- `DESIGN_ENGINE.md`: motion has no overshoot; clip-path reveals end past the
  shadow; the change log now covers v39 and v40.
- `tier_log.csv`: v38 rows closed as superseded, plus a request row recording
  the v38 rejection.
