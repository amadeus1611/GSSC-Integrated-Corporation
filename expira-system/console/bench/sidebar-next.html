Phase two, at a glance

This column stands in for the chat, so the fold has something to push. The sidebar on the left is the v45 draft: hover down the rows, open the folders and the sections, search, and pull the account menu up from the foot.

The sidebar is a small file system now: folders you make, chats and documents inside them, loose chats below, newest first. Drag anything onto a folder (linger and a closed one springs open), or onto open space for the top level. The folder icon beside New chat makes a folder; right-click empty space for the same. Pull the sidebar's edge to resize it; pull it far enough left and it docks.

Keys: F dock, N new chat, S search, D a folder, M a row menu, A account, L loops the dock. With a row focused: arrows walk, right opens, left closes, F2 renames, Delete deletes (and undoes).
